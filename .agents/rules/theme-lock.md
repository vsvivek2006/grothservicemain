# Theme Color Lock Rule

The visual theme for Growth Service is permanently locked to the live production site https://www.growthservice.in/:

- Primary: Royal Purple `#6A0DAD` / `#7C3AED` (`purple-600` / `purple-700`)
- Accent: Gold `#FFD700` (`yellow-400`)
- Top Bar: `from-purple-900 via-purple-700 to-pink-600`
- Hero Sections: `from-gray-900 via-purple-900 to-blue-900`
- Services/Packages Hero: `from-blue-600 to-indigo-700` / `via-blue-700 to-indigo-800`
- About Hero: `from-blue-900 via-purple-800 to-indigo-900`
- Benefits: `from-blue-900 to-purple-900`
- Final CTA: `from-gray-900 to-blue-900`
- Primary CTA Buttons: `from-blue-500 via-purple-600 to-indigo-700 text-white`

NEVER introduce dull slate-950, #1c0836, or arbitrary dark monochrome palettes.
